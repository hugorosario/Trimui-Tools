# Trimui Tools

A system tools app for the Trimui Brick stock firmware.

Menu configurations is defined in the "menu.json" file.

This is the binary used by the BrickTools app for Trimui Brick - https://github.com/hugorosario/BrickTools

The source can be built using the environment at https://github.com/anibaldeboni/trimui-smart-pro-toolchain
